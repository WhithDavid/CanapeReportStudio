# CANape Report Studio

Windows 离线 MF4 波形预览、选段与 CANape 原生出图助手。v0.1.0 功能基线。

## 功能

- 选择观测量、调整图例顺序；离线预览支持公共轴和独立分图。
- 拖动测量线、缩放 X/Y 轴、选择重点时间段。
- CANape 原生黑底、公共 Axis 1、无曲线编号出图。
- 工况模板管理；保存信号、工况、版式、目录，不保存 MF4 路径、时间段及测量线。
- 自选图片目录，按车门、温度、坡度命名；同名图片不覆盖。

## 安装与使用

1. Windows 安装官方 Python 3.12 x64（包含 Tk），运行 `Setup.cmd`。脚本通过 pip 安装依赖，并使用 Windows .NET Framework 编译接口桥接程序。
2. 运行 `Start.cmd`，选择自己的 MF4，读取观测量，选择信号并离线预览/选段。
3. 原生导出另需已安装并有效授权的 CANape x64。设置用户环境变量 `CANAPE_API_DIR` 为厂商安装目录中包含 `CANapAPI64.dll` 的文件夹；重开本工具使环境变量生效。厂商 DLL 不包含在仓库中。
4. 在 CANape 打开自己的工程，关闭设置弹窗，开启 ASAP3 Active。在助手中选择同一工程目录。
5. “检查并生成任务”仅检查数据并生成配置；“连接 CANape 并导出”执行原生出图。图片及日志可在运行结果中查看。

CANape 的打印配色也需设置为黑底；屏幕黑底不一定等于导出黑底。原生模板按已验证环境制作，不保证所有 CANape 版本一致。

## 验证与边界

运行 `python -m unittest discover` 和 `python -m unittest discover -s ReportStudio`。
本发布仅包含源码，不是免安装 EXE；已使用的本机功能基线与公开版路径适配分别验证。没有随仓库提供真实 MF4、客户报告、测量图、个人模板、授权文件或 CANape SDK 二进制。

本工具用于离线出图，不启动 ECU 测量、不写 ECU。不要手动使用桥接程序执行未知脚本。输出图片仍需人工确认信号、时间段、工况和测量线，不能自动视为正式标定结论。
